# ShinePoint MCP (`mcp/`)

Stdio MCP server wrapping the deployed Agent Booking API v1.

Full install + Cursor / Claude Desktop config: **[docs/agent-mcp.md](../docs/agent-mcp.md)**

```bash
npm install
npm run mcp
```

Env: `SHINEPOINT_AGENT_API_KEY` (required), `SHINEPOINT_AGENT_API_BASE` (optional).
